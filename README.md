# When Should We Book?

A full-screen scrollytelling data story about flight prices and availability around
major holidays — Georgia Tech Data Visualization (CS6730) group project (Jet2 Holiday team).

**Story in one line:** you can't predict the cheapest day to buy a flight, but you
can predict the days it gets more expensive — so buy before the 21-day cutoff.

## View it

- Open `index.html` directly in a browser (needs internet for the fonts/D3 CDN).

## Files

- `index.html` — all sections and story text
- `css/style.css` — comic-book styling
- `js/charts.js` — D3 charts (price diary, staircase, heatmap, route curves,
  seats tradeoff, spike odds, minis) plus the title-canvas animation

## Data

Small inline samples from the team process book: Expedia one-way fares searched
Apr 16 – Oct 5, 2022 (Memorial Day, July 4, Labor Day + non-holiday baseline),
BTS DB1C/OD40, and DOT Table 6. Swap in the full CSVs where marked in `charts.js`.
